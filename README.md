# 一键导卡AutoSD / 一键播放AutoPlay

**面向摄影、摄像与后期制作工作流的素材导入与处理工具。**
**附带十分专业高效的播放器**

**软件附带英语，并可轻松方便的增加多种语言至软件内；仅需将语言文件放入软件内的language文件夹即可实现**

一键导卡最初用于解决拍摄后存储卡素材整理、复制和归档的问题。经过持续开发，目前已经形成一套集 **设备识别、校验备份、多任务、转码、素材浏览、专业回放** 于一体的工具。

---

## 核心功能

### 导卡

![主界面](docs/images/主界面.png)

面向相机卡与录音卡设计的素材导入流程。

* 自动识别厂商、型号、序列号和机位
* 支持媒体文件、仅视频、照片、音频以及全盘导入模式
* 支持增量导入、重复素材检测
* 支持断点续传、恢复未完成任务
* 支持多目标导出与备份
* 支持混卡识别与按机型分类归档
* 支持项目名称、机位号、卡号等归档信息

### 素材安全

![完成界面](docs/images/完成界面.png)

导卡过程尽可能围绕“**素材可确认、源文件不误删**”进行设计。

* 导入前检查目标磁盘空间
* 文件导入校验、重复素材检测
* 删除前预检、提供多种校验模式
* 目标文件异常时自动保留源素材
* 导入失败提供详细原因
* 导入完成后生成导出记录

重复检测采用文件名、大小和快速哈希等信息；执行安全删除时可使用更严格的内容校验。


### 相机识别

通过多种素材证据综合判断设备型号

针对未重新格式化、先后使用不同相机的存储卡，也支持混卡识别与机型仲裁，并按照识别结果进行素材归档。

未知设备不会强行套用错误型号，无法确认时会尽可能保留原始信息。

## 多任务队列

导卡和转码任务统一进入任务队列。

支持：
* 多任务并行
* 并发数量控制
* 排队调度
* 程序重启后恢复任务
* 任务完成摘要
* 局域网任务状态查看

---

## 转码

![转码](docs/images/转码.png)
![LUT还原](docs/images/LUT还原.png)

基于随包 FFmpeg / ffprobe 构建。

支持：

* H.264 / H.265 / H.266 / VP9 / AV1 等编码
* 硬件编码加速
* 基础编码调整选项
* HDR → SDR
* 色彩空间转换
* 音频响度标准化
* LUT 还原
* 自定义 FFmpeg 参数
* 自定义预设

![转码详情](docs/images/转码详情.png)

同时提供代理工作流：

* 自动生成 Proxy 文件夹
* 代理文件与原素材关联

## 日志与归档

![日志](docs/images/日志.png)

软件会记录主要业务操作，包括：

* 导入
* 导入历史
* 转码
* 删除
* 删除已转码原素材
* 导入失败
* 相关操作结果

日志支持：

* 搜索
* 筛选
* 分页
* 详情查看
* 自定义日志目录
* 网络共享日志目录

每次导卡完成后，还会在项目目录中维护：

```text
[日期][项目名]_导出详情.xlsx
```

用于记录项目、日期、导出时间、相机、机位、卡号、素材数量、总容量、目标位置、文件状态等信息。

## 性能与可靠性

软件针对大量素材、长时间任务和异常中断进行了专门处理。

包括：

* 大目录虚拟化
* 缩略图按视口加载、缓存
* 后台素材扫描、元数据读取
* 任务状态持久化
* 原子写盘与备份恢复
* 断点续传
* 异常退出后的任务恢复
* 技术日志与业务日志分离

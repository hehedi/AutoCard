# 一键导卡 AutoCard · 一键播放 AutoPlay

**从存储卡导入、校验备份，到转码、素材审阅与播放。**

免费使用 · Windows / Linux · macOS 适配中 · 中文 / English

## 一键导卡 AutoCard

| 功能 | 说明 |
| --- | --- |
| **导卡归档** | 识别设备与混卡；支持按媒体类型或全盘导入，按项目、机位、卡号归档。 |
| **校验备份** | 多目标备份、增量导入、重复检测与空间预检；提供导入校验、删除前预检及多种校验模式，目标文件异常时保留源素材。 |
| **任务管理** | 导卡与转码统一队列，支持并发控制、断点续传、重启恢复及局域网任务状态查看。 |
| **转码与代理** | 硬件加速、HDR → SDR、色彩转换、LUT 还原、响度标准化；自定义预设与参数，自动生成并关联代理。 |
| **工具箱** | 现场在线导入、图片/音频/视频批量格式转换、抽帧与音频提取；工具支持模块化扩展。 |
| **日志归档** | 操作日志可搜索、筛选和查看详情，支持自定义或网络共享目录；导卡后自动生成 Excel 导出记录。 |

![AutoSD 主界面](docs/images/主界面.png)

## 一键播放 AutoPlay

随 AutoSD 提供，可独立打开，用于拍摄素材审阅与日常影音播放。

- **多格式回放**：视频、音频、图片及相机 RAW，支持 DSD、内嵌/外挂字幕和音频设备独占。
- **逐帧审阅**：逐帧定位、精确时间输入、时间码、帧截图与标记；支持缩放拖动、降分辨率回放及掉帧原因提示。
- **画面与声音分析**：亮度波形、直方图、白平衡分析，以及音频波形与频谱；支持画面分析图表叠加显示。
- **A/B 对比**：双视图、单视图与差异比较，支持分离或合并播放、拖入素材替换及截图对照。
- **显示与色彩调整**：自定义 LUT 还原与对比、HDR 亮度适配、SDR 亮度映射；画幅裁切可选择是否影响字幕。

**卡内快速预览**：在 AutoCard 素材浏览器中，将鼠标移到素材卡片上，**按住空格预览，松开关闭**。

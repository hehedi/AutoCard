# 一键导卡 AutoCard

**从存储卡到项目归档，完成素材导入、校验备份、转码与审阅。**

[下载最新版](../../releases) · [AutoPlay](https://github.com/hehedi/AutoPlay) · [AutoLibrary](https://github.com/hehedi/AutoLibrary) · [授权条款](LICENSE)

免费使用 · 离线运行 · Windows / Linux · 中文 / English

AutoCard 面向视频制作、摄影与录音素材管理：识别存储设备中的素材，按日期、项目、机位和卡号整理，支持同时备份到多个目标，并保留校验结果与任务报告。

![AutoCard 主界面](docs/images/主界面.png)

## 核心功能

| 功能 | 说明 |
| --- | --- |
| **导卡归档** | 识别相机、设备与混卡素材；支持按媒体类型或全盘导入，按日期、项目、机位和卡号归档。 |
| **校验备份** | 多目标备份、增量导入、重复检查与空间预检；提供 xxHash（默认）、MD5、SHA-256 内容校验，导卡后删源前再次检查，异常条目保留并提示原因。 |
| **任务管理** | 导卡与转码统一队列，支持并发控制、暂停与重试、导卡续传及符合条件的转码任务恢复；可查看同一局域网内的任务状态。 |
| **转码与代理** | 硬件加速、HDR → SDR、色彩转换、LUT 还原与响度标准化；支持自定义预设和参数，生成并关联代理。 |
| **素材浏览** | 浏览、搜索与筛选卡内素材，查看拍摄参数和媒体信息；按住空格快速预览，支持截图与素材标记。 |
| **工具箱** | 现场在线导入，图片、音频和视频批量格式转换，抽帧与音频提取；支持模块化扩展。 |
| **日志与报告** | 操作日志支持搜索、筛选和详情查看，可使用本地或网络共享目录；导卡后生成 PDF 任务报告，记录素材明细、校验结果、归档位置与删除操作。 |

## 素材浏览器
鼠标指向素材浏览器中的素材，按住空格即可预览；支持保持窗口、截图与素材标记。

- **专业素材回放**：支持 MXF、ProRes、BRAW、R3D、ARRIRAW / ARRICORE 等素材及相机 RAW 照片，可查看拍摄参数与媒体元数据。
- **精确逐帧审阅**：正反向逐帧、SMPTE 时间码、精确定位与帧截图；提供原画及多档回放分辨率，便于检查细节或降低回放负载。
- **LUT 与 HDR 预览**：加载 LUT 查看还原效果，支持 HDR 显示、亮度适配与 HDR → SDR 映射；预览调整不改写源素材。
- **A/B 画面对比**：支持滑动分割、并排比较、参考图或视频、帧对齐与差异图，便于对照原片、代理及不同处理版本。
- **画面与声音分析**：提供亮度波形、RGB 直方图、白平衡辅助，以及分声道音频波形与频谱，辅助检查曝光、色彩和声音。

## 下载与安装

1. 在 [Releases](../../releases) 下载对应版本，平台支持范围以该版本发布说明为准。
2. Windows 安装包中的 `Setup.exe` 与同名 `Setup-1.bin` 数据文件须来自同一版本，放在同一目录后运行安装程序。
3. 安装时可按需选择功能组件。部分专业解码和扩展功能通过可选组件提供，可根据使用需求选择并节省磁盘空间。
